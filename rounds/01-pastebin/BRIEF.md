# Раунд 01 — Pastebin

**Роль AI:** интервьюер + reviewer.  
**Твой deliverable:** `DESIGN.md` + схема в `diagrams/` (например PNG).  
**Время:** не ограничено. Пиши в своём темпе, но одним цельным проходом от начала до конца.  

---

## Задача

Спроектировать сервис в духе **Pastebin / hastebin**: пользователь сохраняет текстовый фрагмент (код, лог, заметку) и получает короткую ссылку, по которой этот текст можно прочитать.

---

## Функциональные требования

**Обязательно**

- Создать paste: принять текст, вернуть `id` / URL вида `https://paste.example/{id}`
- Прочитать paste по `id`
- Задать TTL / expiry (например 1 час, 1 день, 1 неделя, «без срока» в рамках политики хранения)
- Ограничить максимальный размер текста (ты выберешь разумный лимит и обоснуешь)

**Желательно (можно кратко, без глубокой проработки)**

- Опция «сжечь после первого прочтения» (burn after read)
- Подсветка синтаксиса на клиенте (серверу достаточно хранить `language` как метаданные)

**Вне скоупа v1**

- Регистрация пользователей, приватные ACL, команды/организации
- Полноценный поиск по содержимому
- Версионирование правок paste
- Комментарии, лайки, соцсеть

---

## Нефункциональные цели (стартовая точка — уточни и зафиксируй)

Интервьюер даёт ориентиры; ты можешь оспорить и заменить своими assumptions:

| NFR | Ориентир |
|-----|----------|
| Созданий | ~50 пишет/сек в пике |
| Чтений | ~500 читает/сек в пике (read:write ≈ 10:1) |
| Средний размер paste | ~5 KB; максимум ты задаёшь сам (например 1 MB) |
| Latency чтения | p99 &lt; 100 ms |
| Availability чтения | 99.9% |
| Durability | успешный create не должен «пропасть» сразу после 201 |
| Хранение | истёкшие paste должны исчезать (не копить мусор бесконечно) |

---

## На что обратить внимание (без подсказок «как решить»)

Это простая система, но на интервью обычно ждут осознанный выбор по:

1. Где хранить тело paste (БД / object storage / смесь) и почему при твоих лимитах размера.
2. Как генерировать `id`.
3. Как работает expiry (TTL в кэше ≠ удаление из primary store).
4. Burn-after-read, если возьмёшь в скоуп: гонки двух одновременных GET.
5. Что будет при вирусной ссылке на один paste.
