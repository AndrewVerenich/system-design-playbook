# Раунд 00 — URL Shortener

**Роль AI:** интервьюер + reviewer (на следующих раундах не соавтор твоего первого драфта).  
**Образец:** полный эталонный разбор — [`DESIGN.sample.md`](./DESIGN.sample.md); читай как ориентир по глубине.  
**Timebox на свой драфт** (когда будешь повторять без sample): 45–60 минут.

---

## Задача

Спроектировать сервис сокращения URL в духе TinyURL / bit.ly.

Пользователь отправляет длинный URL и получает короткую ссылку. Переход по короткой ссылке делает redirect на оригинал.

---

## Функциональные требования

**Обязательно**

- Создать короткий URL из длинного
- Redirect с короткого кода на длинный URL
- Опциональный custom alias (например `short.ly/my-launch`)
- Опциональный expiry / TTL

**Желательно** (упомянуть, глубокий дизайн можно отложить)

- Базовая аналитика кликов (счётчики во времени)
- Auth / владение ссылками

**Вне скоупа v1**

- Полноценный marketing suite, QR-кампании, A/B landing pages

---

## Нефункциональные цели (стартовая точка — можно оспорить и уточнить)

| NFR | Цель |
|-----|------|
| Масштаб | 100M новых ссылок / месяц |
| Read:write | ~100:1 |
| Latency redirect | p99 &lt; 50 ms |
| Availability (redirect) | 99.99% |
| Durability | не терять mapping'и |
| Код | короткий, URL-safe; обсудить предсказуемость / перебор |
